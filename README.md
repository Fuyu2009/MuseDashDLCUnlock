# Muse Dash DLC 解锁

想购买「计划通」但错过了截止日期？不想花钱买 DLC 但还是想白嫖？这个模组就是为你准备的。

## 使用说明

1. 将 [MelonLoader](https://melonwiki.xyz/#/) 安装到 Muse Dash 文件夹中
2. 将 `MuseDashDLCUnlock.dll` 复制到 `Mods` 文件夹中
3. 享受成果

## Build Instructions

1. 将 [MelonLoader](https://melonwiki.xyz/#/) 安装到 Muse Dash 文件夹中
2. 运行一次 Muse Dash，以生成 Il2Cpp 空心程序集
3. 打开解决方案并构建 DLL

如果构建失败，请确保检查所引用程序集的位置。
